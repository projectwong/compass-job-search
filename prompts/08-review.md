# Prompt 08 Add the weekly review

```text
Build a weekly review command and Markdown output from the canonical private records.

The review must cover:
- targets added, promoted, archived, or reprioritized;
- pipeline state changes;
- conversations completed;
- follow-ups due and overdue;
- evidence that changed a fit or eligibility judgment;
- assumptions that proved wrong;
- the three priorities for next week;
- manual friction observed during the week.

Every priority change needs a reason and supporting record IDs. Keep metrics descriptive. Do not reward application volume or invent productivity scores.

Add a friction log. Recommend automation only after the same friction appears in two completed weekly reviews. A recommendation is not permission to implement it.

Write tests for an empty week, overdue follow-ups, unexplained priority changes, and repeated friction. Generate one synthetic review, show the output, and stop.
```
