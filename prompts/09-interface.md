# Prompt 09 Build the smallest local interface

```text
Before writing code, inspect two completed weekly reviews and name the repeated friction that justifies an interface. If the evidence is absent, stop and say the interface is not justified yet.

If justified, build a read-only local dashboard from an exported snapshot. Bind to 127.0.0.1, make no external requests, and keep the database outside the web root. Use standard-library Python plus plain HTML, CSS, and JavaScript unless the existing project already has a smaller established stack.

Lead with gaps and next actions:
- targets with no qualified warm path;
- overdue follow-ups;
- active opportunities with no next action;
- failed or unknown constraints;
- stale evidence.

The snapshot must omit contact details and private note bodies unless the view needs them. Do not add authentication, hosting, editing, analytics, or a framework.

Write tests for snapshot redaction, localhost binding, empty states, and stable rendering data. Verify the interface at desktop and narrow widths, report what you checked, and stop.
```
